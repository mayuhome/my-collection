# 引导页功能测试指南

## 功能概述
首次启动应用时，会显示三页引导页，介绍应用的主要功能。

## 测试步骤

### 1. 首次启动测试
1. 删除应用（如果已安装）或重置UserDefaults
2. 启动应用
3. 应该看到引导页，显示三页内容
4. 可以滑动切换页面
5. 最后一页有"开始使用"按钮

### 2. 页面导航测试
1. 点击"下一页"按钮，应该切换到下一页
2. 滑动页面，应该能切换页面
3. 页面指示点应该跟随当前页面变化

### 3. 跳过功能测试
1. 在非最后一页，点击右上角"跳过"按钮
2. 应该直接进入主界面

### 4. 完成引导测试
1. 在最后一页点击"开始使用"按钮
2. 应该进入主界面
3. 再次启动应用，应该直接进入主界面，不再显示引导页

### 5. 重置测试
1. 在Xcode中，编辑Scheme → Run → Arguments → Environment Variables
2. 添加：`-com.apple.CoreData.SQLDebug 1`（可选）
3. 或者使用UserDefaults命令行重置：
   ```bash
   defaults delete com.yourcompany.my-collection hasLaunchedBefore
   ```
4. 重新运行应用，应该再次显示引导页

## 功能特点

### 引导页内容
1. **第一页**：📷 "拍下你的藏品" - 介绍图片添加功能
2. **第二页**：🔒 "数据只在你手里" - 强调数据隐私
3. **第三页**：👆 "简单查看，随时回顾" - 介绍查看功能

### 用户体验
- 简洁的界面设计
- 柔和的配色方案
- 大字体，易于阅读
- 大图标，直观明了
- 流畅的页面切换动画

### 技术实现
- 使用 `@AppStorage` 持久化存储启动标志
- 使用 `TabView` 实现水平滑动
- 响应式设计，适配不同屏幕尺寸
- 支持动态类型（字体大小可调）

## 注意事项
1. 引导页只在首次启动时显示
2. 用户可以通过"跳过"按钮直接进入主界面
3. 引导页完成后，无法再次查看（除非重置UserDefaults）
4. 所有数据存储在本地，不会上传到任何服务器

## 故障排除

### 问题：引导页不显示
- 检查UserDefaults中"hasLaunchedBefore"的值
- 确保没有在其他地方设置该值为true

### 问题：页面切换不流畅
- 检查设备性能
- 确保使用最新版本的Xcode和iOS SDK

### 问题：按钮无响应
- 检查视图层级，确保没有其他视图覆盖按钮
- 检查按钮的frame是否足够大（至少44x44点）

## 代码结构

### OnboardingView.swift
- 主视图：`OnboardingView`
- 数据模型：`OnboardingPage`
- 页面视图：`OnboardingPageView`

### my_collectionApp.swift
- 使用 `@AppStorage` 读取启动标志
- 根据标志选择显示引导页或主界面
