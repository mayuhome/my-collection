2. **三页引导内容**：完整实现所有要求的引导页内容

- **流畅动画**：平滑的页面切换效果
- **直观操作**：明确的按钮和指示器

- **状态管理**：`@AppStorage` + `@Binding` + `@State`

- **响应式设计**：适配不同屏幕尺寸

## 使用说明

### 正常使用流程
1. 首次启动应用 → 显示引导页
2. 浏览三页引导内容
3. 点击"开始使用" → 进入主界面
4. 后续启动 → 直接进入主界面

### 重置引导页
```bash
# 使用重置脚本
./reset_onboarding.sh

# 或手动重置
defaults delete com.apple.dt.XcodeDeviceMonitor hasLaunchedBefore
```

### 自定义修改
1. **修改引导内容**：编辑 `OnboardingView.swift` 中的 `pages` 数组
2. **修改样式**：调整颜色和字体配置
3. **添加页面**：在 `pages` 数组中添加新的 `OnboardingPage`
