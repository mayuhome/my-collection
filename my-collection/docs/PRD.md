## 我的收藏 - 个人藏品管理App

---

### 一、产品概述

| 项目 | 内容 |
| :--- | :--- |
| **产品名称** | 我的收藏（暂定名） |
| **产品定位** | 极简、私密的个人藏品管理工具 |
| **目标用户** | 有收藏习惯但不擅操作智能设备的用户（如中老年收藏爱好者） |
| **核心价值** | 用最简单的操作，帮用户记住"我有多少东西、放在哪里、值多少钱" |
| **隐私承诺** | 所有数据仅存于本地和用户私有的iCloud容器，绝不联网传输 |

---

### 二、用户画像

**典型用户：张大爷（65岁）**

-   喜欢收藏邮票和古钱币，家里有几百件藏品
-   经常忘记"这个东西我有没有"、"放在哪个柜子里"
-   会用微信、会拍照，但面对复杂App会感到害怕
-   需要家人偶尔帮忙查看藏品清单

**核心痛点**：
1.  记不清自己有多少件藏品
2.  想找某件东西时翻箱倒柜找不到
3.  买了重复的东西浪费钱
4.  想让子女帮忙看看，但不知道怎么"分享"

### 四、非功能需求

| 类别 | 要求 |
| :--- | :--- |
| **性能** | 瀑布流滑动流畅，图片加载不卡顿；缩略图预生成缓存 |
| **兼容性** | 支持 iOS 16.0 及以上版本 |
| **文件大小** | App包体积控制在 20MB 以内 |
| **稳定性** | 崩溃率低于 1%；图片损坏不影响其他数据读取 |
| **可维护性** | 代码结构清晰，方便未来迭代新分类和新功能 |

### 六、数据模型

```swift
struct CollectionItem: Codable {
    var id: String = UUID().uuidString          // 唯一标识
    var imageFileName: String                   // 图片文件名（如：ABC123.jpg）
    var thumbnailFileName: String?              // 缩略图文件名（缓存用）
    var name: String?                           // 名称
    var category: [String]?                     // 分类（数组，支持多选）
    var source: String?                         // 来源
    var price: String?                          // 价格（文本）
    var location: String?                       // 收藏位置
    var createDate: Date = Date()               // 创建时间（用于排序）
    var modifyDate: Date?                       // 最后修改时间
}
```

**文件结构**：
```
Documents/
├── Items/
│   ├── ABC123.jpg          ← 原始图片
│   ├── DEF456.jpg
│   └── ...
├── Thumbnails/              ← 缩略图缓存
│   ├── ABC123_thumb.jpg
│   └── ...
└── data.json               ← 所有藏品JSON数据
```

### 九、风险与应对

| 风险 | 影响 | 应对措施 |
| :--- | :--- | :--- |
| iCloud同步冲突导致数据错乱 | 用户看到重复或丢失的藏品 | v1.0版本暂不实现CloudKit复杂同步，仅使用iCloud Drive文件级同步；后续迭代逐步增加冲突处理 |
| 图片过多导致App体积膨胀 | 占用用户手机存储空间 | 提供"清理缓存"功能（P2），图片压缩存储 |
| 用户不会操作"从相册选图" | 核心功能无法使用 | 添加首次使用引导（P1），用动画演示点击+选择图片的每一步 |
| App审核被拒 | 无法上架 | 确保隐私政策清晰、功能描述准确、无隐藏功能 |
